# TGPI academic certificate — visual edition 2026.6

The certificate now gives the recipient and course the main reading positions. A centered TGPI crest, fine engraved frame, quiet armillary watermark, restrained gold institutional seal and smaller blue/silver Integrity Chain emblem replace the oversized dark verification rail. The design is original TGPI artwork; external institutions' marks are not included.

## Reference comparison

Reviewed on 20 November 2026. There is no objective global ranking of the most beautiful or most valuable certificates. Visual polish is distinct from academic recognition, employer acceptance and issuer reputation.

## Functional changes

- New original outline-based SVG crest and seals, plus transparent 1600px print masters.
- A4 landscape PDF with embedded fonts, full certificate ID, comparison code and vector QR with a four-module quiet zone.
- Missing completion dates no longer create an empty completion column. Known dates and issuance snapshots remain unchanged.
- New Integrity Chain panel distinguishes live record validity, available Ed25519 portable evidence and the linked identity revision's Base anchor.
- Confirmed identity transactions use a validated transaction hash to construct a fixed Basescan URL. The stored explorer URL is never trusted. Public identity redaction is preserved.
- Revoked, replaced and integrity-review records never receive active-verification proof, even if a historical identity anchor was confirmed.
- Existing PDFs can be downloaded again in the latest visual edition without retaking a course or changing a signed achievement.
- Updated watermarked English/Portuguese home samples. Interface text remains available in all six platform languages; this change retains the existing English/Portuguese PDF language selection.

The decorative seal is the issuer's institutional mark. It does not add government recognition, a professional license, third-party accreditation, a PDF cryptographic signature or certificate blockchain anchoring. The identity anchor is a separate fact from the learning certificate's current status.
