# Capas da Academia TGPI · Direção visual de 2026

As 83 fotografias ilustrativas ficam em `public/images/courses/academy-covers-2026/`, com o slug como nome de arquivo. Foram produzidas individualmente com geração de imagem. Cada cena tem direção de arte própria. O catálogo, a página de cada curso, a área de estudo e os metadados de compartilhamento usam o mesmo arquivo de referência.

## Base comum dos prompts

Fotografia editorial fotorrealista, horizontal, proporção 3:2, cena inteira sem margens. Texturas naturais, direção de luz plausível, profundidade de campo óptica e correção de cor cinematográfica contida. Preservar os elementos principais nos 65% centrais para recortes responsivos. Sem texto legível, logotipo, borda, holograma, selo incorporado ou sobreposição.

A interface aplica os selos temáticos sobre a imagem. Excel, Google Sheets, Power BI, Python e níveis de idioma são identificadores de conteúdo. Para cursos de primeiros socorros, manequins e equipamentos ilustram contextos de treinamento; não são diagramas procedimentais. As cenas são ilustrativas.
