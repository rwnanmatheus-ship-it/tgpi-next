# Original professional course artwork

Ten covers were generated with the built-in image-generation tool on 29 October 2026. They depict fictional illustrative people and workplaces, never actual instructors, students, partnerships, quantitative results or learning evidence. The existing TGPI crest was not modified. The 1672×941 generated sources are not described as 4K masters.

Web assets live at `public/images/courses/professional/{key}.webp` (1600×900, quality 84) and `{key}-card.avif` (640×360, quality 52). Dimensions of each generated source are recorded in `professional-artwork.json`. The protected admin review route uses the WebP covers with explicit dimensions, responsive sizes, lazy loading and descriptive Portuguese alt text. Card AVIF variants are prepared for future catalogue integration.
