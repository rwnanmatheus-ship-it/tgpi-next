# TGPI studio country flags

195 self-contained SVG assets, generated from the sibling flag-icons artwork
(see ../LICENSE) with photographic satin illumination. Paths, emblems, colors
and transparent silhouettes originate from the existing vectors; the filter
adds material lighting without cropping or warping their geometry.

Regenerate from the repository root: `node scripts/generate-studio-flags.mjs`.
The shared fabric-light.jpg is embedded in each SVG for reliable rendering as
an image, without cross-origin dependencies or client-side rendering scripts.
The original flags remain available for language selectors and compatibility.

Material created with the built-in image generation tool, then optimized to a
512 × 384 JPEG for these small interface graphics. The flag geometry remains
resolution-independent. The material prompt was:

> Photographic grayscale satin flag-fabric illumination, edge-to-edge 4:3,
> three broad shallow diagonal undulations, fine woven texture, soft directional
> studio light, bright white highlights and restrained gray shadows; no flag
> design, colors, symbols, text, border, frame, poles or stitching lines.
